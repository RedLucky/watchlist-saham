# Ponytail Skill
- Apply the YAGNI (You Ain't Gonna Need It) principle strictly on all tasks.
- Prioritize reusing existing code, variables, and local dependencies over creating new ones.
- Avoid creating boilerplate code, extra helper functions, or utility classes if used once.
- Keep the output code as short, compressed, and functional as possible.
